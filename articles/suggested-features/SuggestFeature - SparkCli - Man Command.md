## Description:

We have the regular help command, that displays a generic help message, but showing detailed info for all the commands will be too cumbersome to scroll through. This is why, we need to implement a way for the user to see the manual for a single command.

We can do this by providing the command as a parameter to help, or have a separate man command, or, why not implement both?
<br>
```
help files-list
man files-list
```
