## Description:
Some lists are closely related, and we might benefit for a mechanism to
switch between them - for example - 2 unrelated journals a user writes data to.
<br><br>
Sure, a person can add a reference item to the other list - and this is a solution,
but it might be good, to add some user control on the page, to quickly switch the articles.
<br><br>
Same thing with user bookmarks - users can benefit from having that UI control,
and a mechanism they set their bookmarks per list.
