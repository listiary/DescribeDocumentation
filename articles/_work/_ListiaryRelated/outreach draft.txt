Landing/README Copy (polished)

Title: Listiary — the lists-first FOSS wiki engine
Tags: Open Source • Wiki • JavaScript • PHP • C# • ANTLR • DSL

Why Listiary?
Traditional wikis treat lists like second-class citizens. Listiary flips that: it’s a wiki engine built around structured, nested, interactive lists—clearer to read, easier to maintain, and powerful to automate.

What it is

Lists-first model: nested lists as the primary unit of knowledge.

DML (Describe Markup Language): human-readable, machine-parsable syntax compiled with ANTLR4 (C#).

Interactive UI: checkboxes, timed items, sorting, highlighting, drafts, forks, shareable views.

Distributed & sustainable: choose servers/content (Mastodon-style federation goals).

Bot-assisted flows: oracles ingest streams → staging pools → curator bots build journal lists.

Simple, auditable stack: plain JavaScript + PHP + SQL (minimal deps).

Extensible: plugin hooks for features (players, fonts, visual styles).

Ethos: FOSS for public benefit; optional paid private wikis for sustainability.

Status (Prototype)
Usable, not production-ready. Screen-flexible layout; phone and desktop tested.
Focus: core list editing/rendering, DML tooling, plugin interface, distributed hosting experiments.
