## Description:
We might have a decorator like - `{scroll-bottom}` - that, when the user opens a list on a page,
the list is automatically scrolled to the bottom.

But we can also have a decorator like `{scroll-here}` or `{anchor}` - that will get the list automatically
scrolled to that position. We have a similar idea with the editor, as well, described in a different writeup.

### Original draft text:
```
{scroll-bottom} auto scroll list to bottom when loading
```
