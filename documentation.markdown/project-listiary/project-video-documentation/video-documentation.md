<br>
Project Video Documentation is about capturing and explaining the Listiary project through video — showing, not just telling.

While it covers many of the same topics as the written documentation, it approaches them from a different angle, using on-screen examples and real interactions with the Listiary Wiki to make concepts tangible. Videos make it easier for people to see how things actually work, offering quick, visual guidance that complements the more detailed written documentation. This space also includes scripts, production notes, and publishing guidelines to keep our video content clear, accessible, and consistent.
