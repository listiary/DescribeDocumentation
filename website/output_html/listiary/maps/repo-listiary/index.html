DescribeLanguage


The Listiary repository is the home for the Listiary Wiki Engine on the web.
It is the main repository in the organization.


Directories

/.git
The git folder.

/.github
Documents related to GitHub workflows, policies, etc.
Importantly, FUNDING.yml, that sets the URLs for the ‘♡Sponsor’ button.
We also have pull request and issue templates.

/.vscode
A Visual Studio Code special folder. Importantly, containing the JSON config for debugging PHP in VS Code.

/assets
Assets of the project - logos, favicons and screenshots.

/docs
The main documentation lives on the documentation website. This directory is used as a workspace for developing new documentation.

/release
Different version release archives.
At the moment of writing - it is empty, as we have no releases.

/src
The project’s current, up to date, official source code.
Various folders contain all the different modules.

/work
/work/Run1 - Pillars of history
/work/Run2 - Spirit
/work/Run3 - Thunderdome

Files related to ongoing or past development.
I’m experimenting with a new development workflow where we start each “run” in its own branch, under a specific code name. Each run is designed to tackle a distinct set of features, usually tied to a single module. For example, Pillars of history was a run dedicated to the article edit history, Spirit focused on the session/authentication and account modules, and Thunderdome birthed the Spark framework.
