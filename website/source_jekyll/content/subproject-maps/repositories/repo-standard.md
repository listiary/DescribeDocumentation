<br>
This is a convention used to organize the contents of Listiary project repositories.
This is a list of some of the standard folders and files users may find in Listiary project repositories.
Most of these folder names and their general purposes are well known on GitHub and are used across many repositories.
Most of the files are very common across many repositories on GitHub as well, but some are our own implementation.
<br><br>


## Standard repository folders

`/assets`<br>
Files used by the project that are not source code, such as images, fonts, or other media.<br>

`/docs`<br>
Documentation and other files related to documenting the project.<br>
The main documentation lives on the documentation website. This directory may contain a PDF version of the documentation and can also be used as a workspace for developing new documentation.<br>

`/release`<br>
Files prepared for distribution as part of a project release.<br>

`/src`<br>
The project's source code.<br>

`/work`<br>
Files related to ongoing development that are not part of the project's main source or release files.
<br><br>


## Standard repository files

`CHANGELOG.md`<br>
A changelog containing a record of changes made in each version of the software.<br>

`CODE_OF_CONDUCT.md`<br>
A document describing the code of conduct and expected behavior within the repository's community.<br>

`CONTRIBUTING.md`<br>
A document describing the process and guidelines for contributing to the project.<br>

`LICENSE`<br>
The license under which the repository's contents are distributed. Note that it intentionally lacks any file extension - this is the GitHub convention.<br>

`README.md`<br>
The standard readme file for the repository. Its contents are displayed on the repository's home page.<br>

`REPOSITORY_LAYOUT.md`<br>
A document explaining the directory structure and organization of the repository.
