<br>
The [DescribeLanguage](https://github.com/listiary/DescribeLanguage) repository contains the bare minimum specification of the Describe Markup Language - just the grammars and the test cases for developing a compiler.<br>
<br><br>


### Directories<br>

`/Grammar`<br>
This is the folder containing the grammar files for the Describe Markup Language - the older ones for the GOLD parser engine, and the new ones, for ANTLR4. Also, the ANTLR4 jar executable file is here.<br>

`/Highlighting`<br>
Configuration files for highlighting the Describe Markup Language.<br>

`/Media`<br>
Specific media files related to the Describe Markup Language - logos and such.<br>

`/Testing`<br>
This folder contains various test source files and the testing results.<br>
