<br>
This is a listing of the most important Listiary URLs.<br>
This is the full list with explanations about the URLs.<br><br>


### URLs

[Documentation home](https://documentation.listiary.org/)<br>
The homepage of the documentation site.<br>
This is the main documentation hub for the Listiary and Describe projects.<br>

[Listiary documentation](https://documentation.listiary.org/listiary/)<br>
The subsection on Listiary, on the documentation site.<br>

[Describe documentation](https://documentation.listiary.org/language/)<br>
The subsection on the Describe Language, on the documentation site.<br>
<br><br>



[Describe library](https://library.listiary.org/)<br>
A library of many showcase source files for Describe.<br>
For people that want to test their own compiler implementations, and such.<br>

[Documedia library](https://documedia.listiary.com/)<br>
Documedia is a library of assets for the Listiary project.<br>
Many of those are screenshots of the development and testing process.<br>
<br><br>



[Listiary Wiki Demo](https://demo.listiary.org/)<br>
You can visit the prototype and interact with it. 
You will not be allowed to edit content yet, but you can try out a read-only version of the editor and inspect the Describe code in action.<br>

[Listiary Wiki Dev, Pass](https://development.listiary.org/)<br>
Developer-only environment. Password-protected instance used during project development.<br>

[Listiary Wiki Radiowatch](https://radiowatch.listiary.org/m.index.html)<br>
This is an upcoming themed wiki release. Initially planned as read-only.
Includes custom plugins for radio and cloud music streaming, content bots, and other cool experimental features. 
Not yet ready for public release - I give the link as a curiosity.<br>
<br><br>



[Listiary organization on GitHub](https://github.com/listiary)<br>
The Listiary organization on GitHub, that contains all the repositories in the project.<br>

[Listiary repository on GitHub](https://github.com/listiary/Listiary)<br>
The Listiary wiki software repository on GitHub.<br>

[Describe repository on GitHub](https://github.com/listiary/DescribeCompiler)<br>
The compiler for the Describe Marup Language - the markup that powers Listiary.<br>
Also, the core repository for the Describe Language.<br>
