Help you create a config file for your database, checking for invalid values
by trying to establish a connection to the database for you. The output is a timestamped
config file. If you want to use it, you need to remove the timestamp.
<br><br>


### Usage
`php 1set_config.php`<br>
usage (bash) - output to console<br>
