## Description:
When we are using some wrap modes, and this is especially relevant to the mobile version,
and the entry is cut off, we see 3 dots at the end of the entry - signifying that we ran 
out of screen, and the entry was cut off. 
<br>

We can, keep the mode, and make the dots interactive - so when a user clicks on the 3 dots,
the entry is shown on multiple lines.
<br>

We can even make those expand clicks persistent via the metadata layer that we will develop
to save temporary interactions and unsaved edits.
