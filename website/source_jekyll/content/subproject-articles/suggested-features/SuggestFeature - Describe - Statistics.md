## Description:

We should, at some point, support some metadata for the articles in Listiary.
That should probably implemented in the history view module.
It should probably be calculated from the compiler, or from some other script,
or both - depending if it is data for the current article, or for its links to
other scripts as well.
<br><br>
We should probably have a statistics (metrics) table in the database for this.
<br><br><br>

### Original draft text:
```
db tables of statistics, drafts, edit history
```
