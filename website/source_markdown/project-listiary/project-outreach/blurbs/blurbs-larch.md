### Architecture at a glance

* **Core platform:** vanilla **JavaScript** + **PHP** (minimal dependencies)
* **Data:** simple **SQL** storage
* **DML toolchain:** C# + ANTLR 4 compiler
* **Extensibility:** plugin hooks for renderers, behaviors, and UI add‑ons (e.g., players, themes)
* **Distribution:** users choose servers to host or follow (Mastodon‑like federation is planned)

> **Security through simplicity**: keeping dependencies lean reduces the attack surface. (We’ll publish a threat model and security policy as the project matures.)
