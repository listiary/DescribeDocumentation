### Reddit - r/SideProject/

I'm building a new lists-first wiki platform called Listiary, and I'd love some feedback.

Listiary is an open-source wiki-farm built around structured lists. It comes with its own custom markup language (“Describe Markup”), a distributed Mastodon-like model, a plugin system, and bot-driven content pipelines for collecting data from external sources.

It’s built using plain JS, PHP/SQL, and C# with ANTLR.

Repo: *https://github.com/listiary/Listiary*

I’d love any feedback or thoughts.<br>

### Hacker News

Title: ***Show HN: Listiary – A FOSS wiki engine built on nested, interactive lists***
*https://github.com/listiary/Listiary*

Listiary is an open-source, lists-first wiki platform. Instead of treating lists as an afterthought inside long pages, Listiary treats nested, interactive lists as the primary way to structure knowledge.

It comes with its own markup language (Describe Markup Language) and a compiler built with ANTLR, so lists are both human-readable and machine-parsable.

I’d love feedback on the model, the language, and the implementation from people who care about wikis, DSLs, and long-term knowledge organization.<br>
