<br>
Delete all the files in the database.
<br><br>


### Command Syntax
`files-delete [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [Presentation flags manual](/listiary/wiki/spark/v05/pflags/).
<br><br>



### Examples
`php spark.php files-delete`<br>
Delete all the files in the database.
<br><br>
`php spark.php files-delete theme=DEFAULT`<br>
Delete all the files in the database, with presentation flags.
<br><br>
`php spark.php files-delete -hb theme=DEFAULT`<br>
Delete all the files in the database, with presentation flags.
<br><br>
`php spark.php files-delete -auto -hb theme=DEFAULT`<br>
Delete all the files in the database, with presentation flags.
