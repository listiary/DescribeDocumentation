Create the needed tables for the wiki in the database provided in the `_config.php` file.
<br><br>


### Usage
`php 1create_tables.php`<br>
usage (bash) - output to console<br>

`php 1create_tables.php > "output.txt"`<br>
usage (bash) - output to file<br>

`php 1create_tables.php >> "output.txt"`<br>
usage (bash) - append to file<br>

`php 1create_tables.php 2> "errors.txt"`<br>
usage (bash) - capture errors to file<br>

`php 1create_tables.php 2>> "errors.txt"`<br>
usage (bash) - append errors to file<br>

`php 1create_tables.php > "all_output.txt" 2>&1`<br>
usage (bash) - capture output and errors to file<br>

`php 1create_tables.php &> "all_output.txt"`<br>
usage (bash 4+) - capture output and errors to file<br>
