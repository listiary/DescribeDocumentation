Delete all the contents from a database - as means to uninstall the wiki.
<br><br>


### Usage
`php 1wipe_database.php`<br>
usage (bash) - output to console<br>

`php 1wipe_database.php > "output.txt"`<br>
usage (bash) - output to file<br>

`php 1wipe_database.php >> "output.txt"`<br>
usage (bash) - append to file<br>

`php 1wipe_database.php 2> "errors.txt"`<br>
usage (bash) - capture errors to file<br>

`php 1wipe_database.php 2>> "errors.txt"`<br>
usage (bash) - append errors to file<br>

`php 1wipe_database.php > "all_output.txt" 2>&1`<br>
usage (bash) - capture output and errors to file<br>

`php 1wipe_database.php &> "all_output.txt"`<br>
usage (bash 4+) - capture output and errors to file<br>
