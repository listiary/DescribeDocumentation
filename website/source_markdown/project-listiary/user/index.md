<br>
Listiary is an experimental wiki project built around lists rather than articles. The basic idea is simple: lists are treated as their own kind of object, not as formatting inside text. That decision shapes most of the system, from how content is written to how it changes over time.<br>

This section of the site is the user documentation for Listiary.<br>
Unfortunately, it is still under development and is not yet available.<br>
