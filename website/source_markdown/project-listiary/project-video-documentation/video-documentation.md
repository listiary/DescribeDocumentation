<br>
Subproject Video Documentation is about capturing and explaining the Listiary project through videos - showing, not just telling.

While covering many of the same topics as the written documentation, videos approach them from a different angle, using on-screen examples and real interactions with the Listiary Wiki to make concepts tangible. This makes it easier for people to see how things actually work, offering quick, visual guidance that complements the more detailed written documentation.

This section will also support contributors in creating quality videos - demos, tutorials, reviews, and more - and will include scripts, production notes, and publishing guidelines to keep content clear, accessible, and consistent.

It is a work in progress waiting to be started.
