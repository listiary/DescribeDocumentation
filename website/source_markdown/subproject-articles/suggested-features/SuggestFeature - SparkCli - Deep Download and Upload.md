## Description:
Files in the database are named like their namespace names. But we can choose to download them to a flat directory with their long names, or we can reconstruct a path, and then when uploading files, we can construct bach the names from the relative paths.

We will be able to do a deep upload/download - where a file like `foods.vegies.carrotdishes.ds` is resolved to `\foods\vegies\carrotdishes.ds`and uploaded back like `foods.vegies.carrotdishes.ds`
