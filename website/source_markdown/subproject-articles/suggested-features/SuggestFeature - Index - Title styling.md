## Description:
Right now, this does not work properly - using decorator decks indicating colors or style
on list titles.
<br><br>
But they must work like this - the decorators on the item in a list should decorate that item in the list,
and decorators on a title should decorate that title, when the list is opened. On inline lists,
those decorators should do both.
