## Description:

There I had this idea, that I don't know how much merit it has,
but on smaller screens, like on mobile, we can provide different versions
of the same entry - as decorators - same OOP idea - can be implemented as inversions,
where we have multiple shorter versions, and the item is rendered, based on the most
fitting version on the screen.
<br><br>

### Example:

```
 J. K. Rowling - Harry Potter and the Philosopher's Stone ->

	~ Harry Potter and the Philosopher's Stone <short>,
	~ The Philosopher's Stone <shorter2>,
	~ Philosopher Stone <shorter3>;
```
