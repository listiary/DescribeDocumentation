### Description:
We can have an automated pipeline to turn the documentation website to a pdf ebook manual,
that we can then put in different repositories and in releases, and such.
<br><br>

### Original text:
```
In the future, we can automate a pipeline for converting the
documentation website or parts of it to a pdf.

For example, the repository DescribeLanguage does not need the whole documentation
as a book - it just needs the section on the language.

But then, it becomes messier - so I don't know.
But we should definitely have that pipeline,
and include some of the documentation as ebooks in the repos,
on a later stage - if it is beneficial and not adding too much clatter. 
```
