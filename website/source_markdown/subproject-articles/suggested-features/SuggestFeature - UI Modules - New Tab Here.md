### Description:
There should be the option to duplicate the current browser tab in a new tab.
That is, open another Listiary instance, at exactly the same place, and in new browser tab.
<br><br>
This might have the option as a middle button - at the bottom of the page - index page, editor page, etc.
This might also be achievable as an option in the regular menu, called something like "New Tab Here"
