## Description:
In some lists, we add values in brackets.
The idea is that we might use a directive to set a default unit for the article, and the unit symbol
might be appended automatically. 
<br>

For example:<br>
`(20)` might translate to `(20 €)`\
`(20)` might also translate to `(20 kg)`
<br><br>

### The original remark:
```
'(20)' might translate to '20 €'
```
