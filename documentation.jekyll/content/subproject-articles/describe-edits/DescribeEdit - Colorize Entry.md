## Description:
Add the `{color|VALUE}` decorator to the decorator deck of the entry - that is, next to other decorators,
or if no other decorators - then, to the end. VALUE is a valid CSS color name.
<br><br>
If the color decorator is already added to the entry, change the value instead.
