### Description:
In the Describe Compiler, when calculating metrics for a finished job,
well, first of all, we might be calculating metrics, for those multiple files jobs,
and second, we might show the user how many orphaned nodes or lists we have.
We might implement that for some transpilers, on the transpiler level.
<br><br>
However, for Listiary, where we are compiling single files,
this metric will live in a very different place - probably calculated
for the whole database.
