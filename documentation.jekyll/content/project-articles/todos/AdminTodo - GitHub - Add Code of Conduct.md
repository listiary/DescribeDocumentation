## Description:
We need a Code of Conduct file in our Github Repos, and for that, we use the golden
standard, that is the Contributor's Covenant. We have downloaded 2 versions as drafts in this folder as well.
<br><br>
For more information look at the `articles` folder, inside the DescribeDocumentation repo on GitHub,
or look at the Contributor Covenant, version 3.0, permanently available at [https://www.contributor-covenant.org/version/3/0/](https://www.contributor-covenant.org/version/3/0/)
