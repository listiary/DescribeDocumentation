Count the files in the database.
<br><br>


### Command Syntax
`jsons-count [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [Presentation flags manual](/listiary/wiki/spark/v05/pflags/).
<br><br>



### Examples
`php spark.php jsons-count`<br>
Count all the compiled JSON files in the database.
<br><br>
`php spark.php jsons-count theme=DEFAULT`<br>
Count all the compiled JSON files in the database, with presentation flags.
<br><br>
`php spark.php jsons-count -hb theme=DEFAULT`<br>
Count all the compiled JSON files in the database, with presentation flags.
<br><br>
`php spark.php jsons-count -auto -hb theme=DEFAULT`<br>
Count all the compiled JSON files in the database, with presentation flags.
<br><br>
