The goal of Project Maps is to create structured, interconnected lists that visually and textually outline the components of the Listiary (and Describe) Projects — including site sections, domain names, project URLs, and contributor lists. In essence, it serves as a comprehensive directory or “map of maps” that organizes and links together all elements and participants across the projects.

In other words, users come here to easily navigate the Listiary (and Describe) projects, documentation, etc.
